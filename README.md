# 🎬 Netflix Clone

A Netflix-inspired web application that allows users to browse trending movies.  
This project is built with **HTML, CSS, JavaScript** for the frontend and **Node.js, Express, MongoDB** for the backend.  
No external API is used — all movie data is stored in a MongoDB database created by me.

---*

## 📌 Features

- 🔥 **Trending Movies horizontal Scroller ** – Displays trending movies dynamically from MongoDB.
- 🎨 **Responsive Design** – Works smoothly on desktop & other screens.
- ⚡ **Custom Backend API** – Created using Node.js, Express, and MongoDB.
- 📂 **MVC Structure** – Models, Controllers, and Routes for clean code organization.

## 📦 Installation
```bash
git clone https://github.com/HimanshiKhattri/netflix-clone-.git
cd backend
npm install
npm start
```
